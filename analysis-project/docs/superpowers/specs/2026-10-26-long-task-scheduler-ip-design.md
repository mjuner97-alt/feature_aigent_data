# 长任务自动触发读取修复及调度 IP 限制

用户已确认实施：修复 auto_trigger_enabled 查询列及结果映射；在 ai_chat_runtime_config 增加 long_task_scheduler_ip。

仅当配置为本机启用的非回环网卡 IP 时允许 AUTO_METRIC 长任务后台处理。配置缺失、空白、读取异常或 IP 不匹配均拒绝自动任务，并记录原因；MANUAL 和 CHAT 执行不受影响。每个后台入口读取最新配置，不使用聊天会话缓存。配置为单个 IP，不支持主机名、通配符或多个地址；配置地址应为生产服务器本机网卡地址。

保护范围：AUTO_METRIC 执行记录的启动恢复、定时扫描及清理、指标就绪处理、自动触发及补建、事件及后续节点派发。按执行记录的 trigger_type 判断，不以流程定义的开关判断。SQL 在 LIMIT 前过滤，避免自动记录积压阻塞手动和聊天任务；启动恢复 UPDATE 同样按执行记录过滤。已运行中的节点不会因配置变更被强行中断。

迁移默认写入空值，部署后必须填写生产 IP 才会运行自动长任务。不得猜测生产 IP 或修改真实生产库。只修改源码及迁移，不覆盖当前工作区已有前端构建产物。

验证：真实 MyBatis 结果映射回归；IP 匹配、不匹配、缺失、异常、动态更新；未授权机器可处理手动和聊天任务，但不修改自动任务。真实 SQL 覆盖候选分页、跨天等待、耗尽节点、启动恢复。编译及针对性 JUnit 测试。
