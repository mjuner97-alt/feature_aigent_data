# 动态时间弹窗简化

用户已批准方案并要求开始修改。长任务和流程报告统一复用动态时间弹窗。

页面显示规则摘要和修改入口；选择动态时间直接打开窗口，原值直到确认才替换。关闭、取消、Escape 都丢弃草稿。

默认选择上个周期、当前周期、最近 N 个周期，支持月、季度、年。单值或列表根据参数类型自动生成；日期参数自动使用日期格式。月份字符串常用格式仅为“2026年8月份版本”和“2026年8月”，季度及年提供相应格式。历史格式保留，排序及自定义偏移放入高级设置。

界面不显示预览基准日期或手动预览，后端在执行时按数据日期计算。保持保存协议不变，既有自定义窗口及格式不会因打开、取消而改变。非法草稿阻止确认，错误显示在弹窗内。

验证覆盖草稿隔离、取消及确认、新建时取消保留固定值、旧窗口和格式、日期类型、试跑默认日期。运行现有前端测试和构建。
