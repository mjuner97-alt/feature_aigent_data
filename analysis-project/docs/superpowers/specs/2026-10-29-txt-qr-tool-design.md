# TXT 转二维码桌面工具设计

## 目标
提供一个 Windows 桌面程序，用户选择 TXT 文件和输出位置后，程序自动按二维码容量切分文本，生成一组有序 PNG 二维码图片。

## 方案
使用 Python Tkinter 提供本地 GUI，`qrcode` 生成二维码，按 UTF-8 字节切割以避免中文字符被截断。默认每段最多 1000 字节，输出带时间戳的子目录和 `manifest.txt` 清单。清单记录文件序号、字节范围和图片名，便于恢复顺序。

## 交互与错误处理
界面提供“选择 TXT”“选择输出目录”“开始生成”按钮、分段大小输入框、进度条和结果提示。空文件、无效分段大小、读取失败和生成失败均以弹窗提示；输出目录不存在时自动创建。若用户取消选择则不执行。

## 交付
源码位于 `tools/txt_qr/`，包含 GUI、可测试核心逻辑、依赖清单、PyInstaller 打包脚本和使用说明。打包产物为单文件 Windows EXE。
