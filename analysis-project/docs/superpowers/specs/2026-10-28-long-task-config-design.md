# 配置广场长任务配置设计

## 目标
在配置广场中增加长任务配置能力，并通过可管理的任务类型和管理员标签支持自动触发顺序调度。

## 范围
本期包含长任务配置、长任务类型管理、标签管理/绑定、按类型顺序触发和基础校验；不包含类型层级、多类型绑定和复杂编排。

## 领域模型

### 长任务类型
- `id`
- `name`：类型名称，必填且唯一
- `description`：可选说明
- `sortOrder`：管理员维护的触发顺序，数值越小越优先
- `enabled`：是否可被新任务使用和自动触发
- 创建/更新时间

类型由管理员在配置广场的“类型管理”入口维护。支持新增、编辑、停用和排序。类型被长任务引用时禁止直接删除，应先迁移配置或停用类型。

### 长任务配置
- `id`
- `name`
- `taskDefinition`：现有长任务执行内容/参数
- `typeId`：必须关联一个启用的长任务类型
- `priority`：同类型内的执行优先级
- `enabled`
- 创建/更新时间

### 标签
标签独立于任务类型，允许一个长任务绑定多个标签，用于筛选、检索和管理，不改变类型调度顺序。

## 页面设计

### 配置广场
增加“长任务配置”入口/筛选项。列表展示名称、任务类型、标签、启用状态、优先级、更新时间和操作。

新增/编辑表单包含任务基本信息、任务类型单选、标签多选、优先级和启用状态。

### 类型管理
在配置广场顶部管理区或设置菜单中增加“长任务类型管理”。使用列表或抽屉展示类型名称、描述、启用状态和排序。

管理员可以新增、编辑、停用类型，并通过拖拽排序或排序值编辑调整顺序。停用类型不能被新的长任务选择，也不参与自动触发；已绑定配置需要给出影响提示。

### 筛选
支持按任务类型、标签和启用状态筛选长任务配置。

## 自动触发规则
1. 仅选择启用的长任务类型和启用的长任务配置。
2. 先按类型 `sortOrder` 升序。
3. 同一类型内按长任务 `priority` 升序。
4. 优先级相同时按创建时间升序，保证结果稳定。
5. 类型停用或配置停用后跳过，不影响其他类型继续执行。
6. 第一版保留现有长任务的执行/失败机制；如现有机制未定义连续执行策略，调度层只负责确定有序任务集合，不新增重试和补偿语义。

## 接口与校验
- 提供长任务类型的列表、新增、编辑、启停和排序接口。
- 扩展长任务配置的新增、编辑、列表接口，支持 `typeId`、`priority` 和标签。
- 类型名称唯一；排序值有效；长任务必须绑定启用类型。
- 删除类型前校验引用关系；存在引用时返回明确错误。
- 生产环境沿用现有配置广场管理员写权限规则。

## 数据迁移
已有长任务配置需要兼容：为其创建或映射一个默认类型（例如“其他”），并设置默认优先级，确保升级后仍可触发。迁移应可重复执行且不覆盖管理员后续修改。

## 测试与验收
- 类型增删改、启停、排序及名称唯一性。
- 被引用类型的删除保护。
- 长任务绑定类型、标签和优先级的保存与回显。
- 按类型顺序、同类型优先级和创建时间稳定排序。
- 停用类型/配置被跳过。
- 旧配置迁移后仍可正常触发。
- 管理员权限和非管理员只读行为符合现有规则。
