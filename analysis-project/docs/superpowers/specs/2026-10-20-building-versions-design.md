# 在建版本动态参数设计

用户已批准实施，并明确：在建版本选中后仅能预览，不能调整规则。

新增固定标记 {"$dynamic":{"v":1,"kind":"building_versions"}}。仅绑定 string[]、array<string>、array。查询高斯 common 的 rdc_train_calendar，严格沿用用户提供的 CURRENT_DATE SQL、排序及重复行语义，不提供 SQL、日期、窗口、格式、排序编辑入口。日期 varchar 按原 SQL CAST。

保存仅校验标记字段、版本和目标类型，不访问 common；预览及首次执行查询。查询失败明确报错，空结果返回空列表；复用既有执行参数快照确保重试不再查询。前端复用预览 API，异步结果按脚本和参数隔离，显示只读结果及错误。

验证：先编写失败测试，覆盖只读选择/预览、类型和字段校验、保存不查询、顺序及空结果、失败、已有动态时间兼容与快照。
