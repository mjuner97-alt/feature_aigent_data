# 长任务和流程模板动态参数

用户已确认本次范围：修复动态规则标记在参数转换时被破坏的问题，并补齐报告流程模板的参数入口。脚本参数变更后的引用检查和自动迁移不在本次范围。

## 数据约定

- 编辑器用 `scriptParams` 对象保存参数；动态值为 `{"$rule":"rule_key"}`。
- 长任务和报告流程保存、执行使用 `scriptParamsJson`，不得把规则标记转成字符串或数组元素。
- 模板 API 兼容历史 `scriptParams` 对象和已有 `scriptParamsJson` 字符串。编辑、复制时恢复对象；保存时统一写入 JSON 字符串。
- 参数规范化合并 schema 默认值和当前值，保留规则标记（包括待后端校验的非法标记）。

## 界面和执行

模板复用 `FlowNodeCard` 的固定值、数组和动态规则输入。模板隐藏试跑和指标覆盖控件，保持本次范围；长任务恢复规则选择入口，已有但不可用的规则明确显示，不自动替换。

脚本 schema 请求按编辑器会话、节点请求序号和所选脚本校验。加载期间阻止保存，返回的默认值不能覆盖用户已填写的参数，也不能应用到后来选择的另一脚本。

长任务正式执行沿用数据日期解析规则。试跑无任务数据日期，按当天解析规则后再做类型校验，再将具体值交给 Python；不会改写保存的参数。

## 验证

Node 回归测试覆盖重复规范化、JSON 保存、模板 API、新建/编辑/复制、默认值和慢请求竞态。Java 测试覆盖试跑先解析后校验、单值规则适配数组、不可用规则不启动 Python，以及既有调试行为。

全量 Maven 的已有 `ScriptExecTool.java` 编译错误单独记录；本次后端测试在临时源副本中避开该错误，工作区原文件不变。前端构建使用现有 Vite 配置，仅执行时开启 `preserveSymlinks` 规避沙箱 realpath 限制。
