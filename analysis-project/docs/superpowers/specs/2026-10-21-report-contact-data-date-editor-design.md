# 报告联系人、数据截至日期与可执行人编辑权限设计

## 需求

1. 通知报告中的联系人和联系方式在同一行展示。
2. 在联系人上一行展示“报告数据截止日期：YYYY年MM月DD日”，日期取报告执行日期减一天。
3. 流程创建人授权的可执行人同时拥有流程编辑权限。

## 方案

联系人 HTML 由 NotificationContact 统一生成，同一段使用不换行分隔。执行创建时根据执行使用的数据日期计算截至日期并写入执行快照；发送通知和历史报告优先读取快照，跨月/跨年由 LocalDate.minusDays(1) 保证正确。

流程写权限统一由 FlowDefinitionService 的权限守卫判断：创建人或 skill_flow_executor 中的有效授权人可更新、启停、删除、校验及修改通知配置。执行权限继续由现有执行入口校验，授权人不自动成为创建人。前端编辑入口复用详情返回的权限字段，授权可执行人显示并允许编辑。

## 验证

新增 NotificationContact 日期/布局测试、流程授权编辑权限测试，并运行相关 Maven 与前端测试。
