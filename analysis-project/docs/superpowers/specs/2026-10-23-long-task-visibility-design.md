# 长任务“我的/全部”可见范围设计

## 目标
统一长任务定义和执行记录的范围语义。

## 规则
- 长任务定义 `mine` 包含当前用户创建的流程，以及 `skill_flow_executor` 授权当前用户执行的流程。
- 长任务定义 `all` 不按用户过滤。
- 执行记录 `mine` 只包含 `trigger_user_id` 为当前用户的记录。
- 执行记录 `all` 包含全部触发人记录。
- `createdBy` 继续作为创建人/触发人精确筛选条件。
- 长任务编辑、启停和删除允许创建人及授权可执行人；授权管理沿用现有创建人校验规则。

## 验收
覆盖分页和非分页查询、范围切换、授权用户、本人触发与他人触发组合。
