# 动态参数保存和重试快照

用户已确认：当月随每次新执行的数据日期变化；同一执行重试沿用首次解析的实际参数。预设规则选择时复制计算配置，历史引用仍可执行。

保存长任务和报告流程模板时，将顶层 `$rule` 转成完整 `$dynamic`，保留偏移和格式，不计算具体月份。不批量修改历史记录。新配置统一经周期窗口校验；不可用规则拒绝保存。

节点执行增加可空 TEXT 字段 `resolved_script_params_json`。首次解析后通过带状态、尝试次数及租约所有者条件的原子更新写入；写入失败不能执行脚本。后续尝试直接读取该字段，不重读规则或用 schema 重新计算。自动重试、手动节点重跑、服务重启都保留快照。新执行初始为空，按新的 data_date 计算。已有执行无此字段值的，在升级后首次运行时冻结，不能恢复升级前的实际输入。

快照只冻结输入，不冻结脚本文件、业务数据或注册表；保留现有执行安全检查。不将实际参数覆盖回流程定义。缓存和日志使用同一实际参数。

验证覆盖保存转换、规则更改后的独立性、跨月新执行、重试不重新解析、空参数、损坏快照、写入失败以及 Mapper 映射和重试保留。
