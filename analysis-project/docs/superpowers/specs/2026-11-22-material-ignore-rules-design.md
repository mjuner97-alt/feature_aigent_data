# 材料类型忽略规则设计

## 目标

让每种材料类型拥有可扩展的页面忽略规则。第一版支持目录关键词和章节编号，用户上传材料时选择材料类型，系统据此在导入核对阶段自动标记页面为不识别。

## 规则模型

材料类型与忽略规则是一对多关系。规则包含：

- `type`：`KEYWORD` 或 `CHAPTER`
- `value`：关键词文本或章节编号，例如 `目录`、`2`、`3`
- `scope`：`PAGE` 或 `SECTION`
- `enabled`：是否启用

第一版界面只允许创建两种规则，底层保留规则类型和作用范围，后续可增加标题、页码或其他匹配方式而不改材料类型字段结构。

## 匹配行为

### 目录关键词

当页面标题或页面提取文本包含规则关键词时命中。`目录`规则的默认作用范围为当前页。

### 章节编号

章节标题支持阿拉伯数字和中文序号，例如 `2-经营情况`、`2. 经营情况`、`2、经营情况`、`第二章 经营情况`。章节规则的默认作用范围为整个章节，从命中的章节起始页开始，到下一个章节标题起始页之前结束。

章节标题需要能被识别为同一套章节编号。无法识别下一章节时，忽略范围延续到材料末尾。

## 生效流程

1. 上传页面时选择材料类型。
2. 服务端读取该材料类型启用的忽略规则。
3. 解析页面标题和文本，先计算章节边界，再应用关键词和章节规则。
4. 命中的页面在导入核对页显示为“整页不识别”。
5. 用户仍可在核对页修改本次导入结果。
6. 保存版本时固化本次页面的识别模式，后续修改全局规则不改写历史版本。

## 配置示例

月度例会可以保存：

```text
KEYWORD  目录  PAGE
CHAPTER  2     SECTION
CHAPTER  3     SECTION
```

季度例会可以只保存目录和第三章规则。规则数量不设为三个固定字段。

## 暂不支持

- 按日期、批次名称或上传人动态匹配
- 自定义正则表达式
- 第四章以上的专用快捷选项
- 章节范围以外的复杂条件组合

## 验收标准

- 不同材料类型可以保存不同的忽略规则集合。
- 目录规则只忽略命中的目录页。
- 章节规则忽略命中章节到下一章节前的所有页面。
- 无规则的材料类型保持现有识别行为。
- 导入核对页可人工覆盖自动标记。
- 历史版本保存后不受后续规则变更影响。
