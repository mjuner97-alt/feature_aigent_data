# weekly_demo 本地报告模板演示设计

## 目标
提供一个隔离于真实业务数据的完整报告模板执行闭环，注册 `weekly_demo`，通过 `script_exec(scriptId="report_template:weekly_demo")` 生成周报，并验证缺失模板仍按原约定失败。

## 范围
- 演示数据仅写入项目 `tmp/weekly-demo/`。
- 模板固定包含周期、项目进展、指标摘要、风险、下周计划五个章节。
- 支持重复执行与重置，不接入真实数据库，不改变生产模板注册表。
- 输出 Markdown、HTML 和结构化执行结果，便于人工检查和自动验证。

## 方案
增加一个本地演示执行器，复用仓库现有脚本/报告格式约定；模板注册表使用项目内 JSON 文件模拟，执行器负责读取模板、合并演示数据、渲染输出并返回结果。通过命令行入口完成 seed、exec、verify、reset 四步。

## 错误处理
模板不存在或 disabled 时返回 `ReportTemplateNotFoundOrDisabled`；数据缺字段时返回明确字段错误；执行结果写入 JSON，失败不会覆盖上一次成功报告。

## 验证
运行演示命令完成注册、执行和验证；检查输出报告五个章节、模板编码、执行状态和错误分支。
