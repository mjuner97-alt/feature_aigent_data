# 混合省略日期区间解析修复方案（“9月28-9月30日”形态）

> 状态：2026-11-04 设计并实施（93 维度测试 + 594 skills 包 + 26 middleware 包全绿；E2E 待内网）
> 上游底稿：`docs/202610/time-dimension-plan.md`（§3 正则形态清单）、`docs/202610/dimension-key-dynamic-dimension-plan.md` §6.1（timeRange 保留键链路）

## 1. 问题现象

问句：

> 杭州开发三部，10、11月版本，9月28-9月30日之间QI卡口到期的，但还有指标未达标的

期望解析：

```json
{"dev_dept":["杭州开发三部"],
 "version_plan":["2026年10月份版本","2026年11月份版本"],
 "start_date":"2026-9-28","end_date":"2026-9-30"}
```

实际解析（2026/11/04 14:53 E2E）：

- `version_plan` 多出 **`2026年9月份版本`**（错）；
- **`start_date`/`end_date` 完全缺失**（错），params 只带了 dev_dept + version_plan。

## 2. 根因分析

问句里的日期区间是**混合省略形态**：左段「9月28」省了“日”，右段「9月30日」重复了月份。现有四个区间正则（`TimeRangeExtractor`）全部不覆盖：

| 正则 | 形态要求 | “9月28-9月30日” 为何不命中 |
|---|---|---|
| `CN_RANGE` | 两段都 `M月D日` | 左段无“日” |
| `CN_RANGE_TAIL` | 左段 `M月D日` + 右段裸 `D日` | 左段无“日”；右段带“月” |
| `DAY_RANGE` | 两段都裸 `D日` | 左段带“月” |
| `NUM_RANGE` | 数字日期 `yyyy.M.d` | 非数字形态 |

由此产生两个连锁错误：

**Bug A（主）— 无时间锚点**：`TimeRangeExtractor.extract` 产不出 `DATE:2026-09-28~2026-09-30` 锚点 → `extraDimensions.timeRange` 为空 → `DirectSkillExecutor.valuesFor(timeRange.start/.end)`（DirectSkillExecutor.java:1714、`timeRangeEdge`:1767）返回空 → `start_date`/`end_date` 不传参。

**Bug B（连带）— 版本误收**：`DimensionStateManager.dateShieldSpans`（:699）= `absoluteDateSpans` + `BARE_DATE_SPAN`（:343，要求 `M月D[日号]`）。左段「9月28」无“日”不被任何屏蔽覆盖 → 屏蔽后文本 `9月28-█████之间` 上 `EXPLICIT_VERSION`（:303，`(\d{1,2})月份?(?!延后)版本?`）吃出「9月」→ 归一成 `2026年9月份版本`。右段「9月30日」有 BARE_DATE_SPAN 屏蔽，所以错只来自左段。

注：整条提取链（正则 + 词表 contains）是确定性的、零 LLM，versionPlan 误收**完全由 Bug B 解释**；修复屏蔽 span 后 `extractExplicitDimensions`（:979 dateSpans）、`collectBuiltinVocabHits`（:1323）、`DimensionSpanScanner`（timeShieldSpans）三个消费方自动痊愈，无需各自改动。

## 3. 方案设计

### 3.1 新增 MIXED_RANGE 正则（TimeRangeExtractor）

覆盖「左段省‘日’」的混合区间：左段 `[年]M月D`（无日），右段三形态——`[年]M月D[日号]`（重复月）/ `M月D`（重复月省日）/ 裸 `D[日号]?`（省月）。

```java
/** 混合省略区间：[年]M月D[日号]? (到|至|~|…) [年][M月]D[日号]? — 左段无“日”
 *  （实施时补 [日号]? 兼容“12月28号-30号”），右段月份可重复（“9月28-9月30日”）
 *  可省略（“9月28-30日”），日可省（“9月28-9月30”）。
 *  左段带“日”的形态归 CN_RANGE / CN_RANGE_TAIL（先跑，优先占 span）。 */
private static final Pattern MIXED_RANGE = Pattern.compile(
        "(?:(\\d{4})\\s*年\\s*)?(\\d{1,2})\\s*月\\s*(\\d{1,2})\\s*[日号]?"
                + "\\s*(?:到|至|~|～|—|–|-)\\s*"
                + "(?:(\\d{4})\\s*年\\s*)?(?:(\\d{1,2})\\s*月\\s*)?(\\d{1,2})\\s*[日号]?");
```

- 分组布局：1=起始年(可选) 2=起始月 3=起始日 4=结束年(可选) 5=结束月(可选) 6=结束日。
- 专用 `mixedRangeAnchor(Matcher)`：年补齐规则——右段有月时缺年补**起始年**（跨年须显式写年，与 CN_RANGE 同口径），右段省月时年/月全承左段；`LocalDate.of` 越界（13月等）抛异常 → 返回 null 整段跳过（与 `rangeAnchor` 同语义）。
- **插入位置**：`collectL1Spans` 中 `CN_RANGE` 之后、`NUM_RANGE` 之前。与 `CN_RANGE` 无重叠（左段带“日”时本正则因“日”挡在分隔符前不命中），带“日”全形态仍由先跑的 `CN_RANGE` 占据。

### 3.2 屏蔽联动（零改动，自动生效）

`absoluteDateSpans`（:120）过滤 `collectL1Spans(datesOnly=true)` 中 `DATE:`/`UNTIL:` 前缀锚点，MIXED_RANGE 加入日期组后：

- `extractExplicitDimensions` 的 `dateSpans` 屏蔽整段「9月28-9月30日」→ Bug B 消失，`2026年9月份版本` 不再产生；
- 词表 contains（`collectBuiltinVocabHits`）、检索词条 span 屏蔽（S4）同步受益。

### 3.3 参数贯通（配置侧核查，非代码）

`valuesFor`/`timeRangeEdge` 链路已存在，锚点修复后即产出 ISO `2026-09-28`/`2026-09-30`。需核查 DB 侧 `wenshu_qi_budabiao` 的 `param_mapping` 是否已绑定 `timeRange.start → start_date`、`timeRange.end → end_date`（本次 params 完全没带这两个键，锚点缺失与映射缺失两种可能都存在，锚点修复后复测即可分辨）。

### 3.4 明确不做

- **不放宽 `BARE_DATE_SPAN` 的 `[日号]` 为可选**：裸「9月28」（无区间上下文）独立出现时语义偏版本/模糊日期，放宽会让 `10月26版本` 类文本被误屏蔽。本次只修区间形态；裸 `M月D` 无“日”的单独场景留待真实 case 驱动。
- **不动 `EXPLICIT_VERSION`/`RANGE_VERSION`**：屏蔽是统一防线，改消费方正则会顾此失彼（10/27 裸日期屏蔽先例同口径）。

## 5. 测试计划

新增（TimeRangeExtractor）：

1. `9月28-9月30日之间` → `DATE:2026-09-28~2026-09-30`（本 case，右段重复月带日）
2. `9月28-30日` → 同上（右段省月）
3. `9月28-9月30` / `9月28-30` → 同上（右段省日）
4. `2025年9月28-10月2日` → 右段缺年补起始年 2025
5. `9月28-13月5日` → 非法月，整段跳过（无锚点）

回归（不得被 MIXED_RANGE 破坏）：

6. `10月1日到10月15日` → CN_RANGE 先占，单锚点
7. `10月1日到15日` → CN_RANGE_TAIL
8. `5日到10日` → DAY_RANGE
9. `截止10月26日` → UNTIL
10. `10、11月版本` → 不产出任何日期锚点（分隔符 、 不在集合内），versionPlan 仍收两个版本
11. `10-12月26日` 型 → RANGE_VERSION 口径不回归
12. 本 case 全句：versionPlan 恰为 `[2026年10月份版本, 2026年11月份版本]`（无 9 月）、timeRange 锚点存在、`timeRangeEdge` 产出 `2026-09-28`/`2026-09-30`

### 7.3 边界与降级（行为说明）

| 问句片段 | 行为 | 原因 |
|---|---|---|
| `2025年12月28-1月2日` | **无锚点**（整段跳过） | 右段缺年补起始年 2025 → start>end 非法 → 弃收；跨年混合形态须右段显式写年（`2025年12月28-2026年1月2日` 走 CN_RANGE），与既有 CN_RANGE 同口径，不做方向猜测 |
| `9月28-13月5日` | 无锚点 | 13 月非法，`LocalDate.of` 抛异常整段跳过 |
| `9月28到期的`（裸日期，无区间） | 不在本轮范围 | 无区间上下文，`BARE_DATE_SPAN` 放宽有误屏蔽风险（§3.4 明确不做） |
