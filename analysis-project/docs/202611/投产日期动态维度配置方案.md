# 投产日期动态维度配置方案（前端页面配置指引）

> 2026-11-17 立项并实施完毕（331 维度单测过，E2E 待内网）。
> 需求：动态维度「投产日期」——出参 `XXXX-XX-XX`（ISO）；逻辑：用户问题同时出现
> 「投产」和一个日期。示例：「XX月XX日投产的情况如何」「投产日为XX月XX日的XX情况如何？」

## 0. 结论速览

投产日期 = **普通动态维度键**（非内置键），走 dimension_key_config 词表配置，
前端「维度管理页」新建键 + 2 行**正则捕获词表**（synonym 类型 + value 含 `$n`）即可，
**零代码改动**（本次为支撑它补了两处引擎通用能力，见 §5）。

| 项 | 值 |
| --- | --- |
| key（脚本参数名） | `prodDate`（建议，驼峰；也可按脚本侧参数名另取） |
| label（页面显示） | `投产日期` |
| builtin | 否（普通动态键） |
| enabled | 是 |
| 词表行类型 | `synonym`（**不是** regex 类型——正则捕获模板是"synonym 类型 + value 含 $n"，见 §3 坑①） |
| 出参形态 | `["2026-10-26"]`（ISO 数组，缺年补当前年） |
| 脚本侧 | param_mapping：`prodDate` → 脚本参数（如 `prod_date`） |

## 1. 维度管理页配置步骤

前端入口：配置广场 → 维度管理（DimensionKeyPage）→ 新建维度键。

**第一步：新建键**

- key：`prodDate`
- label：`投产日期`
- enabled：勾选

**第二步：给该键添加词表（aliases），两行，类型均选 synonym**

| 行 | alias（正则） | value（捕获模板） | 覆盖问法 |
| --- | --- | --- | --- |
| ① 后缀形态 | `(?:(\d{4}|\d{2})年)?(\d{1,2})月(\d{1,2})[日号]\s*投产` | `{year:$1}-$2-$3` | 「10月26日投产的情况」「2026年10月26日投产的」「26年10月26日投产」 |
| ② 前置形态 | `投产日[期]?[为是:：]?\s*(?:(\d{4}|\d{2})年)?(\d{1,2})月(\d{1,2})[日号]` | `{year:$1}-$2-$3` | 「投产日为10月26日的…」「投产日期是2026年10月26日的…」「投产日：10月26日」 |

两行分组布局一致：**$1=年（可省） $2=月 $3=日**；value 模板相同 `{year:$1}-$2-$3`。

**第三步：保存**。保存期校验（DimensionKeyController）会检查：
alias 必须是合法正则；value 引用的最大组号 $3 不得超过 alias 捕获组数——
两行 alias 各有 3 个捕获组，合法。校验不过会 400 并返回错误描述。

## 2. 脚本侧配置（skill 配置页）

1. 脚本的 `params_schema` 加参数：如 `prod_date`（string，非必填）；
2. param_mapping：`prodDate` → `prod_date`；
3. 未配置 param_mapping 时该键不传参（fail-safe），不会报错。

脚本收到形态：`prod_date = "2026-10-26"`（若一个问句命中两处不同日期，为
`["2026-10-26", "2026-11-01"]` 数组，脚本侧自行处理；正常问法只有一处）。

## 3. 正则捕获词表机制（为什么这么配）

词表 value 含 `$1`~`$9` 时（AliasRegexSupport，dimension-key 动态维度方案 §6.4）：

- alias 按正则对问题 find 循环匹配，每次命中的捕获组替换进 value 模板；
- `{year:$n}` 补年令牌（本次新增）：`$1` 组命中取捕获年（2 位补 `20` 前缀，
  与引擎 `yearOf` 同口径）；组为空（省略年）→ 取**当前年**（Asia/Shanghai，
  同 TimeRangeResolver 时区）——「10月26日投产」→ `2026-10-26`；
- 行类型必须是 **synonym**（即非 regex 类型）：type=regex 的行有独立语义
  （alias 整体作正则、value 是字面值），不会走捕获模板。

**坑①（最重要）**：类型下拉里别选 `regex`。正则捕获词表 = synonym 类型 + value 含 `$n`。
选了 regex 类型，value 里的 `$1` 会被当字面量产出 `"{year:$1}-$2-$3"` 这种垃圾值。

**坑②**：value 里 `$n` 引用组号必须真实存在（保存校验拦截）；
`$1` 是可选年前缀组，组空由 `{year:…}` 兜当前年，不会漏产出。

**坑③**：alias 中的中文冒号/空格按需写全：`[为是:：]?` 同时含半角/全角冒号；
`\s*` 允许「投产日期 是 …」中间带空格。

## 4. 与时间范围维度（timeRange）的关系——让位护栏

投产日期里的日期**不是时间范围**，timeRange 轨必须让位，否则同一日期会被
timeRange（DATE 过滤）和 prodDate（属性过滤）双过滤，结果必错。两层护栏：

- **后缀形态**「10月26日投产」：BARE_DATE 正则自带 `(?!\s*投产)` 护栏，
  timeRange 不出（裸日期单日方案 §8.2 拍板⑦，已上线）；
- **前置形态**「投产日为10月26日」：本次给 BARE_DATE 加前置 lookbehind
  `(?<!投产日[期]?[为是：:]?\s{0,3}(?:\d{4}|\d{2})年\s{0,3}|投产日[期]?[为是：:]?\s{0,3})`
  ——两支备选：含年支压引擎内移重试（「2026年10月26日」起点被压后，正则引擎
  会重试到「10月26日」，须由含年支再压一次），裸前缀支压无年形态（拍板⑨）。

护栏验证（TimeRangeExtractorTest.bareDateYieldsToProdDatePrefix）：
「投产日为10月26日的缺陷」「投产日为2026年10月26日的缺陷」→ timeRange 空；
「10月26日到期」→ 照出单日 DATE。

**已知边界**：区间形态「投产日为10月26日到10月30日」CN_RANGE 区间正则先占 span
仍会出 timeRange DATE 区间（与 prodDate 并存双过滤）。属生僻问法，未加护栏；
真出现时脚本侧 prodDate 参数与 timeRange 并存，业务可自行取舍。

## 5. 本次引擎侧改动（配置能力的代码前提，均已实施）

1. **AliasRegexSupport 补年令牌 `{year:$n}`**：replaceYearTokens 先于 $n 替换
   （组空→当前年、2位年→20YY）；isRegexTemplate/maxCaptureGroup/保存校验
   无需改动（`{year:$1}` 含 `$1` 自然计入）。
2. **TimeRangeExtractor.BARE_DATE 前置让位护栏**：见 §4；
   注意 lookbehind 里年份用非捕获 `(?:\d{4}|\d{2})`——若用带捕获组的 YEAR_G
   会插入 group 1 使 bareDateAnchor 的组号整体后移（实施时避开的坑）。

## 6. E2E 验证清单（内网）

1. 「10月26日投产的应用情况」→ prodDate=["<当前年>-10-26"]，脚本参数收到，
   timeRange 无 DATE；
2. 「投产日为2026年10月26日的缺陷」→ prodDate=["2026-10-26"]，timeRange 空；
3. 「26年10月26日投产」→ prodDate=["2026-10-26"]（2位年补 20）；
4. 「10月26日到期的应用」→ 不产 prodDate，timeRange 出 DATE 单日（回归）；
5. 「10月29日投产的应用」（后缀形态回归）→ timeRange 仍空（§8.2 护栏不回退）；
6. 缺参数反问轮：问「XX应用投产情况」（有投产无日期）→ 不产 prodDate（两行
   alias 都要求日期同时出现），走正常链路。

## 7. 配置 JSON 速查（API 直配时）

POST /v2/dimension/key（管理员）：

```json
{
  "key": "prodDate",
  "label": "投产日期",
  "builtin": false,
  "enabled": true,
  "aliases": [
    { "alias": "(?:(\\d{4}|\\d{2})年)?(\\d{1,2})月(\\d{1,2})[日号]\\s*投产",
      "value": "{year:$1}-$2-$3", "type": "synonym" },
    { "alias": "投产日[期]?[为是:：]?\\s*(?:(\\d{4}|\\d{2})年)?(\\d{1,2})月(\\d{1,2})[日号]",
      "value": "{year:$1}-$2-$3", "type": "synonym" }
  ]
}
```

注意 JSON 里正则反斜杠双写（`\\d`）；页面上手填单写（`\d`）即可。
