# 裸日期单日时间范围识别方案

> 状态：**已拍板（2026-11-10，§6 全部拍板）待实施**。
>
> 需求：时间范围内增加**单独日期**识别——口语里只出现一个裸日期（M月D日 / M月D号）时，
> 时间范围 start = end = 该日。业务例句：
>
> - `10月29日卡口达标率 11月版` → timeRange = 2026-10-29 ~ 2026-10-29，版本 = 11月版
> - `10月29号卡口达标率 11月版` → 同上（"号"形态同命中）
>
> 上游方案：`docs/202610/time-dimension-plan.md`（时间维度口语值，本文沿用其 L1/L2、
> 锚点 DSL、span 屏蔽全套骨架）；关联案例：该方案 §9 测试点 2 的
> "杭州三部11月版、12月版10月26日到期"——裸日期彼时被刻意定为**仅屏蔽不产出**，
> 本方案按 2026-11-10 拍板**放开为统一出单日区间**（行为变更，见 §6①②）。

## 1. 现状与缺口

| 形态 | 例句 | 现状 | 定性 |
|---|---|---|---|
| 区间 | 10月29日到10月31日 | **已有**（CN_RANGE / MIXED_RANGE 等 6 组） | 无改动 |
| 截至X日 | 截至10月29日 | **已有**（UNTIL 锚点） | 无改动 |
| 裸日期+指标 | 10月29日卡口达标率 11月版 | **缺**——裸日期只进屏蔽 span（`DimensionStateManager.BARE_DATE_SPAN`），不产时间锚点 | 本方案 |
| 裸日期+事件词 | 12月版10月26日到期 | 屏蔽 span，不产锚点 | **拍板①②：行为变更**——同样出单日锚点（见 §6） |

缺口根源：`TimeRangeExtractor` 现有正则全部要求区间分隔符（到/至/~/-）或前缀词
（截止/截至），裸 `M月D日` 无出口；而 `DimensionStateManager` 侧的 `BARE_DATE_SPAN`
只负责防版本词表误吃"10月"，两侧都没把它当时间范围。

## 2. 方案：复用 DATE: 锚点，产出 `DATE:{d}~{d}`

**不新增锚点类型。** 单日 = start 与 end 相同的绝对区间，直接产出
`DATE:2026-10-29~2026-10-29`，下游全自动受益、零改动：

- `TimeRangeResolver.resolveDateRange`：`start.isAfter(end)` 仅拒倒序，start==end 合法
  （TimeRangeResolver.java:152），`{d}~{d}` 直通；
- `.start/.end` 后缀键绑定：与既有 DATE: 同路径，两键各得同一天，脚本无感知差异；
- 裸键 `timeRange`：透传锚点原词，与既有 DATE: 一致；
- ResponseCache 绕过：`containsTimeRangePhrase` 走 `extract()` + `absoluteDateSpans()`
  双路（ResponseCacheMiddleware.java:179-195），只要提取层产出 DATE: 锚点即自动绕过，
  **无需新增判定**；
- 版本屏蔽：`absoluteDateSpans()` 过滤 `startsWith("DATE:")` 会自然收下裸日期 span，
  与 `DimensionStateManager.BARE_DATE_SPAN` 双保险（span 重叠无害），"10月29日"里的
  "10月"继续不会被版本词表误收。

## 3. 提取层改动（TimeRangeExtractor，唯一改动点）

### 3.1 新增 L1 正则（排在全部日期区间正则之后，span 优先级最低）

```
// ⑧ 裸日期单日：[年]M月D(日|号) → DATE:{d}~{d}（缺年补当前年，同 UNTIL/CN_RANGE 口径）
//    拍板①②：不设事件词护栏——除 截止/截至（归 UNTIL）外，任何裸日期一律出单日区间
BARE_DATE = "(?:(\\d{4})\\s*年\\s*)?(\\d{1,2})\\s*月\\s*(\\d{1,2})\\s*[日号]"
```

- 分组布局：1=年(可选) 2=月 3=日；`bareDateAnchor` 合法性校验同 UNTIL
  （13月32日整段跳过、DateTimeException 兜底）；
- **位置**：`collectL1Spans` 的日期组末位（DAY_RANGE 之后）。区间正则先跑先占 span，
  与裸日期重叠的命中被 `addRegexSpans` 丢弃——`10月29日到10月31日` 出区间不出单日；
- **实施细化（区间邻接护栏，2026-11-11 实施时补）**：区间正则产出非法/倒置时锚点为
  null（无 span 占位），裸日期会把端点兜底收走单日——`10月15日到10月1日`（倒置）、
  `2月30日到3月1日`（起点非法）会漏出 `DATE:end~end`，违背原"整段弃收"语义。
  故 BARE_DATE 追加两个邻接护栏：后接分隔符+数字（`到10`/`-30日` 型）不命中、
  前接分隔符（`到|至|~|…`，含至多 3 空白）不命中。"到期"的"到"后接"期"非数字，
  不受影响（拍板①照出单日）；"截止10月29日"由 UNTIL 先占 span，护栏冗余但无害；
- **截止/截至归 UNTIL 不变**（拍板①）：截止/截至 [年][M月]D日 → 取数年1月1日
  （未明确年份默认当年）~ 对应截止日期，UNTIL 正则先跑、span 重叠天然互斥，
  裸日期正则不重复产出；
- 形态上与 `DimensionStateManager.BARE_DATE_SPAN` 同一正则——后者继续只做版本屏蔽，
  本方案在提取层给它补上时间锚点出口。

### 3.2 不配 L2 词表 seed

裸日期是数字形态，按既定拍板（"近N个版本走正则不进词表"同款约定）走 L1 正则，
词表只收封闭短语，本期无新增封闭词。

## 4. 联动影响面确认（均为零改动）

| matchesDriftRegex | 单日是绝对日期不随今天漂移，不纳入，零改动 |

## 6. 拍板点（2026-11-10 已全部拍板）

| # | 问题 | 结论 |
|---|---|---|
| ① | 事件词护栏集合 | **护栏取消**——除 截止/截至（维持 UNTIL 语义：取数年1月1日，未明确年份默认当年，~ 对应截止日期）外，**只要出现裸日期一律出单日区间** `DATE:{d}~{d}`；到期/上线/投产/交付/验收/为止均不拦 |
| ② | "10月29日起…" | **照出单日** `DATE:2026-10-29~2026-10-29`（不做 FROM:{date} 开区间） |
| ③ | 数字形态 2026-10-29 / 10.29 | **不做**——"10.29"与小数/版本号撞车，NUM_RANGE 要求两端日期同理 |
| ④ | 裸 "29日"（无月） | **不做**——误伤面大（"15日上线"类零散文本），同"截至15日"拍板④"日/号必带"同一理由 |
| ⑤ | "10月29日有哪些需求"类疑问句 | **照出单日** |
| ⑥ | 是否需要歧义反问 | **不需要**——单日语义无方向/口径歧义 |

> 拍板①② 的行为变更：原设计"到期日≠查询时间范围"的护栏（时间维度方案 §9 测试点 2）
> 按业务口径放弃——`杭州三部11月版、12月版10月26日到期` 现在会同时产出
> 版本维度（11月版/12月版）与 timeRange 单日（2026-10-26~2026-10-26），
> 既有单测/E2E 断言需按此改写。

## 8. 动态参数特例：`x月x日投产` → 出参 `投产日=x月x日`

> 2026-11-10 追加。业务存在"投产日"脚本参数：问句 `10月29日投产`（的应用有哪些）
> 语义是**按投产日属性过滤**，参数应出 `投产日=10月29日`，而不是（或不仅仅是）
> timeRange 单日——日期+后缀"投产"是属性语义，与拍板⑤"10月29日有哪些需求"
> （查当天的数据）的查询时间语义相反。

### 8.1 承接机制：动态键正则捕获模板（零代码）

`extractExtraDimensions`（DirectSkillExecutor.java:2353）对非内置字典键已支持
**正则捕获模板**（AliasRegexSupport，我X方案 §8.1 引入）：alias 按正则匹配、
捕获组替换 value 里 `$1`~`$9` 产出维度值；`valuesFor` default 分支直读
extraDimensions，保存期校验（validateRegexRow）齐备。因此投产日**纯配置可接**：

- 维度管理页新增启用键 `投产日`（非内置键），alias 配正则行：
  `alias = (\d{1,2})月(\d{1,2})[日号]\s*投产`，`value = $1月$2日`
- skill 侧 param_mapping 配 `投产日 → 脚本参数名`；无映射的 skill 参数不传
  （既有 fail-safe，与其它动态键同口径）
- 前置形态（如需）再配一行：`投产日[期]?[是:：]?\s*(\d{1,2})月(\d{1,2})[日号]` → 同模板

### 8.2 唯一代码点：BARE_DATE 为"投产"让位

不处理则 `10月29日投产` 同时产出 timeRange=`DATE:2026-10-29~2026-10-29` 与
`投产日=10月29日`，双过滤（按查询日期又按投产日属性）必错。落点一行：

```
BARE_DATE = "...(\\d{1,2})\\s*[日号](?!\\s*投产)"
```

与拍板①"护栏取消"不矛盾：①取消的是"事件词→不出锚点"（吞掉）；这里是
"事件词→**换出口**"（timeRange 不出、投产日参数出），是让位不是吞掉。
"10月29日上线/到期/起"等其余事件词不受影响，仍出单日（拍板①②原样）。

### 8.3 拍板点（⑦⑧⑨，2026-11-10 已拍板）

| # | 问题 | 结论 |
|---|---|---|
| ⑦ | 投产日命中时 timeRange 单日还出吗 | **不出**（让位，§8.2）——双过滤语义必错 |
| ⑧ | 投产日参数值形态 | **原词 `$1月$2日`**（"10月29日"，脚本自解析，同里程碑透传哲学）——ISO 形态模板补不了年（alias 可选年捕获组缺省时 substitute 返回 null 整行跳过），要 ISO 需脚本侧补年或加代码 |
| ⑨ | 形态范围 | 先只配后缀形态 `M月D[日号]投产`；前置形态（"投产日期是10月29日"）按需再加正则行，纯配置零发布 |

> **本期实施范围**：投产日键/词表/param_mapping 的页面配置由业务**后续自行配置**（§8.1
> 纯配置可接，零发布）；本期代码只含 §8.2 BARE_DATE 让位一处 + 单测。
> 配置备忘（业务自配时照抄）：维度管理页新增启用键 `投产日`（非内置键），
> alias 正则行 `(\d{1,2})月(\d{1,2})[日号]\s*投产` → `$1月$2日`。

## 7. 测试要点

1. **正例**：`10月29日卡口达标率 11月版` → DATE:2026-10-29~2026-10-29 + 版本仅 2026年11月份版本
   （"10月"被屏蔽不出 10月份版本，回归口语值方案测试点 2）；`10月29号…`"号"形态；
   `2026年10月29日…` 带年；`10月29日卡口达标率` 无版本形态；
2. **事件词场景（拍板①②行为变更）**：`杭州三部11月版、12月版10月26日到期` →
   版本 11月版/12月版 + timeRange=DATE:2026-10-26~2026-10-26（原"无 timeRange"断言改写）；
   `10月29日上线` / `10月29日起…` → 均出单日锚点；
3. **投产日让位（拍板⑦，§8）**：`10月29日投产的应用` → timeRange 不出（lookahead 让位）、
   投产日=10月29日（extraDimensions）；`预计10月29日投产` 同；无投产日 param_mapping 的
   skill → 两参均不出投产日（fail-safe）+ timeRange 不出；
4. **区间优先**：`10月29日到10月31日` → 仅 DATE 区间不出单日；
   `截止10月29日`/`截至10月29日` → 仅 UNTIL（取数年1月1日~截止日，裸日期被 span 重叠吃掉）；
   `9月28-9月30日`（混合省略）回归 11/04 方案；
5. **非法日期**：13月32日整段跳过；`10月0日`/`10月39日` 同；
6. **解析/绑定**：`DATE:{d}~{d}` → start=end={d}；`.start/.end` 后缀键各得同一天；
   裸键收到 `DATE:2026-10-29~2026-10-29` 原词；
7. **缓存**：裸日期命中 → 绕过（extract/absoluteDateSpans 双路验证，不需要改 middleware）；
8. **回归**：全量基线（870+）+"到期"案例按新口径改写 + 混合省略区间案例 +
   本周/近N天等既有口径不变。
