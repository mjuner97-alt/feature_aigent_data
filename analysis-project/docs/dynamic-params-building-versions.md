# 在建版本动态参数

在长任务节点的脚本参数中，字符串数组参数可选择“在建版本”。选择后保存固定规则，点击“预览参数”查询当前实际版本列表；该类型不提供周期、数量、格式、排序或日期调整，也不能逐项编辑结果。

## 数据与执行

- 数据源：高斯 common 数据库，表 `rdc_train_calendar`。
- 复用 `VersionPlanKnowledgeHook#VERSION_PLAN_SQL`，以数据库 `CURRENT_DATE` 为准；返回 `string[]` 版本列表，按投产日期排序，保留查询原有重复行，不返回单个版本字符串。
- 日期列为 varchar，按 SQL 转成 DATE。日期数据不能转换或连接失败时，预览/执行明确报错。
- 保存规则不查询 common 数据库；预览不运行脚本。
- 首次正式执行查询并冻结实际参数，重试复用冻结列表。预览与正式执行时间不同，结果可能不同。
- 没有匹配记录时结果为 `[]`。

## 参数协议

```json
{
  "versions": {
    "$dynamic": {
      "v": 1,
      "kind": "building_versions"
    }
  }
}
```

`versions` 是示例参数名，实际使用脚本 schema 中声明的参数名。仅接受 `string[]`、`array<string>` 和 `array` 类型。固定配置仅有 `v`、`kind` 两个字段，不能传入自定义 SQL 或覆盖查询条件。

common 数据源需已启用并拥有该表的读取权限。本功能不创建或修改业务表。
