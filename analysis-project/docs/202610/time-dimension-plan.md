**# 时间维度口语值处理方案**

> 状态：已实施（2026-10-19，P1+P2 同日落地；E2E 待内网验证）。
> 实施落点：`TimeRangeExtractor`（7 组新正则 + 中文数字周数"两周/临近交付两周内"）、
> `TimeRangeResolver`（白名单/滚动口径/TODAY/UNTIL/NEXT/LAST:{n}w + 歧义辅助）、
> `DimensionKeyConfigRepository`（seed 扩充 + 存量行首版 seed 自动升级）、
> `DirectSkillExecutor`（歧义反问 pending，`DirectExecutionPlan.askMessage` 自定义反问全文）、
> `ResponseCacheMiddleware`（字典不可用兜底路径补周类漂移正则）。
> 与设计的差异：① 近X周**含"近一周"**一律歧义反问（业务表追问行逻辑，原 seed 的
> 近一周/最近一周→LAST:7d 已从 seed 移除，被 L1 正则遮蔽；近7天/近30天不受影响）；
> ② 周类正则支持中文数字（业务例句"临近交付两周内"原话，含"两"）；③ "截至X日"的"日/号"为必带
> （设计稿 `[日号]?` 可选会导致"截至15人"类误命中）。
> 用途：落地业务需求表（2026-10-19）里的**时间维度**口语词，补齐 timeRange 保留键
> 尚未覆盖的锚点形态。上游底稿：`docs/202610/dimension-key-dynamic-dimension-plan.md` §6.1
> （timeRange 已实施部分，本文不重复其推导）；配套方案：`docs/202610/版本季度部门口语值处理方案.md`
> （版本/季度/部门三键，本文只管时间）。
> 本文"§6.1"指底稿 timeRange 章节，"§N"默认指该底稿章节。

## 1. 现状盘点（需求表逐行对照）

| 需求表行 | 口语词 | 现状 | 缺口定性 |
|---|---|---|---|
| 今天 | 今天、今日 | **缺**（无 TODAY 锚点） | 词表 seed + 解析 |
| 截至X日 | 截止X日、截至X日 | **缺** | L1 正则 + UNTIL 锚点 |

结论：**已有骨架完全够用**（timeRange 保留键 + L1/L2 两层提取 + 锚点解析 + 后缀键绑定 +

NEXT/LAST:{n}w/里程碑透传）；③ 歧义反问接入。

## 2. 锚点 DSL 扩展（TimeRangeResolver 白名单）

分两型，**解析行为不同**：

### 2.1 日期计算型（执行期算 start/end，解析结果不进指纹/缓存）

| 锚点 | 语义 | 解析产出（ISO，含端点） |
|---|---|---|
| `TODAY` | 今天 | today ~ today |
| `UNTIL:{yyyy-MM-dd}` | 截至X日 | 取数年1月1日 ~ X日（年缺省补当前年） |
| `NEXT:{n}w`（n≥1） | 未来 n 周 / 下周（n=1） | today ~ today+7n（含今天，拍板②③） |
| `LAST:{n}w`（n≥1） | 历史近 n 周 | today-7n+1 ~ today（含今天，与 LAST:{n}d 同构） |

CONFIG_ANCHOR 白名单追加：`TODAY|NEXT:[1-9][0-9]*w|LAST:[1-9][0-9]*w|UNTIL:\d{4}-\d{2}-\d{2}`。
`UNTIL:` 与 `DATE:` 同理**仅 L1 正则产出，禁止人工配置**。
拍板②结论：**不设独立 NEXT_WEEK 锚点**，"下周"就是 `NEXT:1w`（today~today+7），
词表 seed 直接映射，锚点集合更小。

### 2.2 里程碑透传型（不解析日期，锚点值原样传给脚本）

| 锚点（=透传值本身） | 口语词来源 | 依据 |
|---|---|---|
| `交付周至投产周` | 交付周到投产、交付周至投产、交付到投产、交付至投产、交付前一周至投产、交付前一周到投产、交付前到投产、交付后 | 需求表"直接传'交付周至投产周'" |
| `投产周` | 投产周、投产前一周 | 需求表"直接传'投产周'" |
| `T-{n}`（n≥1） | T-X、T-5周 | 需求表"直接传'T-X'" |
| `R-{n}`（n≥1） | R-X、临近交付{n}周内 | 需求表"直接传'R-X'" |

设计要点：
- **锚点值即脚本收到的字面量**——复用 §6.1.6 裸键 `timeRange` 透传机制，零新增绑定代码；
  后缀键 `.start/.end` 对透传锚点解析为 null → 参数不传 → 回退 LLM（与 LAST:{n}V 暂缓期同语义）；
- 白名单：`^(交付周至投产周|投产周|T-[1-9][0-9]*|R-[1-9][0-9]*)$`，与日期型共用
  `isValidConfigAnchor`（分型校验）；
- **透传锚点不绕过 ResponseCache**（确定性字面量，指纹稳定可缓存）——仅 2.1 日期型绕过，
  判定集合见 §5。

## 3. 提取层（TimeRangeExtractor 扩展）

### 3.1 L1 正则新增（全部确定性，代码内置）

```
// ① 截至X日：截止/截至 [年][M月]D日 → UNTIL:{date}（非法日期整段跳过，同 CN_RANGE 语义）
UNTIL_P = "(截止|截至)\\s*(?:(\\d{4})\\s*年\\s*)?(?:(\\d{1,2})\\s*月\\s*)?(\\d{1,2})\\s*[日号]?"
   缺年补当前年；缺月补当前月（拍板④："截至15日"→本月15日）；
   月/日均需合法性校验，非法（13月32日）整段跳过

// ② 同月省略区间（第二段无"月"）：10月1日到15日
CN_RANGE_TAIL = "(?:(\\d{4})\\s*年\\s*)?(\\d{1,2})\\s*月\\s*(\\d{1,2})\\s*日\\s*(?:到|至|~|～|—|–|-)\\s*(\\d{1,2})\\s*[日号]?"

// ③ 双省月区间（当前月）：5日到10日 → 本月5日 ~ 本月10日
DAY_RANGE = "(\\d{1,2})\\s*日\\s*(?:到|至|~|～|—|–|-)\\s*(\\d{1,2})\\s*[日号]?"

// ④ 未来X周：(未来|今后|下)([1-9][0-9]*)周 → NEXT:{n}w；"下周"裸词走 L2 词表
NEXT_WEEKS = "(?:未来|今后|下)\\s*([1-9][0-9]*)\\s*周"

// ⑤ 近X周：近([1-9][0-9]*)周 → 歧义标记（见 3.3），不做方向假设；含"近一周"（拍板按业务表追问逻辑）
LAST_WEEKS = "近\\s*([1-9][0-9]*)\\s*周"

// ⑥ T-X / R-X：T-5周、R-2 → 透传锚点（周后缀可省）
MILESTONE = "([TR])[-—]\\s*([1-9][0-9]*)\\s*周?"  →  T-{n} / R-{n}
```

注意：
- ② ③ 必须排在 CN_RANGE **之后**跑（长的先占 span），且命中后进 span 表参与屏蔽；
- ③ 有误伤风险（"15日上线"类零散文本），要求**必须含分隔符**才命中（正则已保证），
  且日期非法（32日）整段跳过；
- ② ③ 产出的日期 span 全部并入 `absoluteDateSpans()`——版本词表扫描继续屏蔽
  （"10月1日到15日"里的"1月"不得被 versionPlan 词表误收，口语值方案 §3.2 同源约束）；
- 正则优先级即 span 屏蔽顺序：CN_RANGE → NUM_RANGE → UNTIL → CN_RANGE_TAIL →
  DAY_RANGE → MILESTONE → NEXT_WEEKS → LAST_WEEKS（数字周词先于 L2 词表，
  防止 seed 里"近一周"之类短词抢先）。

### 3.2 L2 词表 seed 扩充（dimension_key_config timeRange 行，ensureReservedRow 补种缺失行）

| alias → value | 型 |
|---|---|
| 今天→TODAY、今日→TODAY | 日期型 |
| 当周→THIS_WEEK | 日期型（拍板①：口径改为倒推7天） |
| 下周→NEXT:1w | 日期型（拍板②：下周=未来1周，不设 NEXT_WEEK 锚点） |
| 交付周到投产→交付周至投产周、交付周至投产→交付周至投产周、交付到投产→交付周至投产周、交付至投产→交付周至投产周、交付前一周至投产→交付周至投产周、交付前一周到投产→交付周至投产周、交付前到投产→交付周至投产周、交付后→交付周至投产周 | 透传型 |
| 投产周→投产周、投产前一周→投产周 | 透传型 |
| 投产前→AMBIGUOUS:PROD | 歧义型（见 3.3） |
| R-X→（不配 seed，数字形态走 L1 正则） | — |

> "未来{n}周/下{n}周/近{n}周/T-{n}/R-{n}"是数字形态，按约定**走代码正则不进词表**
> （与"近N个版本走正则"同一拍板）。"临近交付{n}周内"含数字，同样走 L1 正则
> `临近交付\\s*([1-9][0-9]*)\\s*周内? → R-{n}`，词表只收无数字封闭短语。

### 3.3 歧义反问（复用缺参反问 pending 机制）

DirectSkillExecutor 已有缺参反问基建（DirectSkillExecutor.java:343-416，pending 按
userId:conversationId 存、TTL 5min、一次只问一个口径）。歧义场景复用该基建，
触发方式与缺参不同——**提取命中歧义锚点 → 不进执行计划，直接产反问**：

| 歧义词 | 反问文案 | 用户补参后 |
|---|---|---|
| 近{n}周 | "您说的近{n}周是指历史近{n}周（往前推），还是未来近{n}周？" | 回答含"历史/往前"→ LAST:{n}w；含"未来/往后"→ NEXT:{n}w |
| 投产前 | "您说的'投产前'是指投产周，还是交付周至投产周？" | 二选一 → 对应透传锚点 |

实现形态（拍板点⑤）：
- 提取层产出特殊锚点 `AMBIGUOUS:WEEKS:{n}` / `AMBIGUOUS:PROD`；
- `valuesFor` / `timeRangeEdge` 遇 AMBIGUOUS 锚点 → 走反问分支（不解析、不传参、
  不静默回退 LLM——回退 LLM 会让小模型瞎猜方向，违背表格"追问"行原意）；
- 反问 pending 复用现有存储；用户答复在**同一轮追问上下文**里补参后重放执行计划
  （同缺参反问"补参→继续"链路）；
- 用户答非所问/超时 TTL 过期 → 回退 LLM（现有兜底语义不变）。

## 4. 解析层与绑定（TimeRangeResolver / DirectSkillExecutor）

- `resolve()` switch 追加：`TODAY` / `NEXT:{n}w` / `LAST:{n}w` / `UNTIL:{date}`；
  **口径修订（拍板①）**：`THIS_WEEK` 语义从"周一~今天"改为 today-6 ~ today（倒推7天含今天）；
  为保持"上周=本周整体前移7天"的滚动直觉，`LAST_WEEK` 同步改为 today-13 ~ today-7
  （**已实施行为变更**，TimeRangeResolverTest 周一/跨月用例需改写回归）；
  里程碑透传锚点与 `LAST:{n}V` 同路径——**resolve 返回 null**（不解析日期），仅裸键透传；
- 裸键 `timeRange` 语义不变：传锚点原词。日期型锚点透传的是 `THIS_WEEK` 这类 DSL 词
  （脚本自解析），透传型锚点透传的是 `T-5`/`交付周至投产周` 这类业务字面量——两类
  在裸键行为上天然一致，无需特判；
- `.start/.end` 后缀键：日期型新锚点正常出区间；透传型/歧义型出 null → 不传 →
  回退 LLM。param_mapping 里给透传锚点配后缀键属于配置错误，保存期校验放过
  （无法静态判定用户问句会命中哪型），运行期按上述降级；
- 多锚点：维持"后缀键取第一个"边界（§6.1.6）。

## 5. ResponseCache 绕过范围

- **绕过**（值随"今天"变）：TODAY / THIS_WEEK / NEXT:{n}w / LAST:{n}w /
  LAST:{n}d / UNTIL:{date} / DATE:{a~b}（绝对区间虽确定，但 DATE: 是 L1 产物，
  沿用现有"timeRange 命中即绕过"的粗粒度判定，不细分）；
- **不绕过**：里程碑透传锚点（T-5 / R-2 / 交付周至投产周 / 投产周）——确定性字面量；
  AMBIGUOUS 锚点根本不进执行（反问），与缓存无交点；
- 实现：`containsTimeRangePhrase` 的 L1 判定新增上述正则（截至/未来X周/近X周/T-/R-），
  L2 词表判定天然覆盖（读的就是 timeRange 行 aliases，seed 扩了就生效）。

## 7. 拍板点（2026-10-19 已拍板）

| # | 问题 | 结论 |
|---|---|---|
| ① | "本周"口径：需求表写"当前日期倒推7天"，已实施拍板为"周一~今天" | **按需求表：本周=today-6 ~ today（倒推7天含今天）**；连带 LAST_WEEK 同步滚动（today-13 ~ today-7）保持口径自洽，已实施行为需回归 |

| ⑥ | "交付后"单词条归"交付周至投产周" | **按需求表原文归并**；上线后观察误命中再拆 |

## 9. 测试要点

1. **L1 正则**：截至10月15日/截止2026年10月15日 → UNTIL 正确；"截至15日"缺月补当前月；
   13月32日整段跳过；
