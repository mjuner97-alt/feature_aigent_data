# 时间口径分类维度（timeSpan）配置文档

> 状态：已实施（2026-10-30，纯配置，无代码改动）。
> 用途：通过维度键字典新增动态键 `timeSpan`，把问题的时间口径归类为 **全年 / 版本 / 半年** 三种
> 互斥状态，以参数形式传给脚本，供脚本侧分支处理。
> 机制依据：动态键同义词行 value 含 `$n` 时 alias 按正则模板匹配（`AliasRegexSupport`，
> `DirectSkillExecutor.extractExtraDimensions`），`$0` = 整个命中片段。

## 1. 前置结论（模板值限制）

- 模板值只能取自**问题文本捕获内容**，产不出与问题无关的常量（"半年"恰好是问题字面词可用捕获）；
  因此三态的区分放在**脚本侧归类**，词表行只负责"命中 + 产原始片段"。
- 行类型必须选**同义词**（不是"正则"）：type=regex 的行会被 `extractExtraDimensions` 直接跳过，
  regex 型是 myDept/block 用途标签机制，不产参数值。

## 2. 字典配置（新增动态键 timeSpan，三行词表，类型均为"同义词"）

### 行 1：半年（同义词行，contains 命中）

| alias | value |
|---|---|
| `半年` | `半年` |

- 命中：上半年 / 下半年 / 近半年（"半年"是"上半年"的子串，包含命中）。
- 若只要裸"半年"（排除上半年/下半年），改为正则模板行：alias `(?<![上下])半年`、value `$0`。

### 行 2：版本（年份词锚点 + 可选"全年/当年"中缀 + 月份版本或裸版本）

```
alias: (?:\d{2,4}年|本年|当年|全年)\s*(?:全年|当年)?\s*(?:\d{1,2}月份?(?:版本?)?|版本)(?!\d{1,2}[日号])
value: $0
```

- 覆盖：`xx年xx版本`、`xx年全年xx版本`、`xx年当年xx版本`、`本年xx版本`、
  以及无月份的 `本年版本 / 当年版本 / xx年版本 / 全年版本`（2026-10-30 两轮修正补入）。
- `(?!\d{1,2}[日号])` 挡裸日期（"10月26日"不算版本）。
- 年份锚点含 `全年`：`全年版本` 归版本；`全年` 后面没跟版本（如"2026年全年的缺陷"）仍归行 3。

### 行 3：全年（整句锚定，排除半年/版本/季度形态后出现年份词）

```
alias: ^(?![\s\S]*(?:半年|(?:\d{2,4}年|本年|当年|全年)\s*(?:全年|当年)?\s*(?:\d{1,2}月份?(?:版本?)?|版本)(?!\d{1,2}[日号])|\d{1,2}月份?(?:版本?)?(?!\d{1,2}[日号])|\d{1,2}月\d{1,2}[日号]|[一二三四五六七八九十]{1,2}月(?:份|版)本?|(?<![0-9])20\d{2}(?:0[1-9]|1[0-2])(?![0-9])|近\d+个版本|近\d+个月|在建版本|延后版|这个版本|那个版本|各月|每月|各版本|今年以来|\d{1,2}季度|[一二三四]季度|当季|在建季度)).*(?:\d{2,4}年|本年|当年|全年).*$
value: $0
```

- 语义：全句**无任何**版本形态、无半年、无季度、无裸日期时，出现年份词 → 全年。
- 排除表条目与行 2 同步维护（首条即行 2 完整形态，防"xx年版本"漏挡）。
- `[\s\S]*` 而非 `.*`：与 `^...$` 整句锚定配合，避免换行类字符绕过负向断言。

## 3. 传参配置

- `params_schema`：`{"name":"timeSpan","required":false,"type":"array"}`（白名单外不传，必须声明）。
- `param_mapping`：`{"timeSpan":"timeSpan"}`。
- 动态键仅当前问题提取，不跨轮继承。

## 4. 脚本侧归类（三行 → 三态）

```python
vals = params.get('timeSpan', [])
if any('半年' in v for v in vals):
    time_type = '半年'      # 半年优先 (行3已排除半年, 但行1与行2可能同时命中)
elif any('月' in v or v.endswith('版本') for v in vals):
    time_type = '版本'      # 行2命中值含"月"或以"版本"结尾; 行3命中值两者皆无
elif vals:
    time_type = '全年'
else:
    time_type = None        # 未提年份/版本, 走脚本默认口径
```

区分依据：行 2 的命中值必然含"月"或以"版本"结尾；行 3 的命中值（如 `2026年`/`本年`）两者皆无。

## 6. 维护注意

1. 行 3 排除表与行 2、以及 versionPlan 提取的形态（A 类正则 + B/C 类词表）需**三处同步**：
   versionPlan 新增口语词时，行 3 排除表要补对应形态，否则"提到了版本却归全年"。
2. 误判危险方向：把版本问题归成全年 → 脚本走全年口径出错；漏判（三态皆无）走脚本默认，安全。
3. 保存后需点字典页"刷新解析快照"（否则等 TTL 5 分钟）再验证。
