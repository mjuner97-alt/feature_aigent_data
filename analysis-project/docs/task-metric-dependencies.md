# 任务依赖指标来源

任务创建和编辑页面不再提供依赖指标配置。

- 长任务的 Python 节点读取脚本注册中的默认指标；旧 Skill 节点读取关联 Skill 的默认指标。
- 普通、部门和团队报告使用同一指标来源；报告模板单独执行时也按脚本指标统计就绪情况，沿用原有聊天/手动执行不等待指标的规则。
- 独立任务目前关联 Skill，读取该 Skill 的默认指标。
- 历史任务级指标覆盖不再参与列表展示、指标就绪检查或新执行的自动触发。旧客户端提交的任务级指标字段也不会恢复覆盖。
- 保存任务时清空任务级覆盖；脚本或 Skill 没有配置指标时，不回退到历史任务指标，也不会因指标就绪自动执行。
- 指标在脚本注册或 Skill 设置中维护，修改后影响后续触发；已有执行记录保持原快照。

长任务列表继续保留依赖数据查看入口。独立任务列表显示继承的指标；自动通知沿用首个指标的通知配置。

自动触发仍要求任务及调度开关开启、当天排程允许、全部生效指标当天就绪，且当天没有对应自动执行记录。
