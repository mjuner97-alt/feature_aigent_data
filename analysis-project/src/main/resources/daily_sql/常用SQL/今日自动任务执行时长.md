# 今日自动任务执行时长统计

## 口径说明

| 口径 | 字段/条件 | 说明 |
|---|---|---|
| 自动任务 | `skill_flow_execution.trigger_type = 'AUTO_METRIC'` | 长任务流程定时自动触发 |
| 调起时间 | `skill_flow_execution.created_at` | 任务生成/调起时刻；若按"实际开始执行"算，换成 `started_at` |
| 邮件发送时间 | `skill_flow_notification.sent_at` | 状态为 `SENT / ACCEPTED / SIMULATED`（SIMULATED 为演练模拟发送） |
| 统计范围 | `created_at::date = CURRENT_DATE` | 只统计今天调起的任务；跨天完成的任务不计入 |

## 一、汇总

> 今天全部自动任务：第一个任务调起时间 → 最后一个任务邮件发送时间，得出整体总耗时。

```sql
WITH today_auto_exec AS (
    SELECT e.id,
           e.flow_id,
           e.flow_name,
           e.created_at,
           e.started_at,
           e.completed_at,
           e.status
    FROM skill_flow_execution e
    WHERE e.trigger_type = 'AUTO_METRIC'
      AND e.created_at::date = CURRENT_DATE
)
SELECT
    COUNT(DISTINCT t.id)                                                        AS "任务总数",
    MIN(t.created_at)                                                           AS "第一个任务调起时间",
    MAX(n.sent_at)                                                              AS "最后一个任务邮件发送时间",
    ROUND(EXTRACT(EPOCH FROM (MAX(n.sent_at) - MIN(t.created_at))) / 60.0, 1)   AS "总耗时(分钟)",
    ROUND(EXTRACT(EPOCH FROM (MAX(n.sent_at) - MIN(t.created_at))) / 3600.0, 2) AS "总耗时(小时)"
FROM today_auto_exec t
LEFT JOIN skill_flow_notification n
       ON n.flow_execution_id = t.id
      AND n.status IN ('SENT', 'ACCEPTED', 'SIMULATED')
      AND n.sent_at IS NOT NULL;
```

## 二、明细

> 每个自动任务一行：调起/开始/完成时间、本任务执行耗时、首封/末封邮件发送时间、接收人。
> "最后一封邮件发送时间" 为 NULL 表示该任务未开启邮件通知。

```sql
WITH today_auto_exec AS (
    SELECT e.id,
           e.flow_id,
           e.flow_name,
           e.created_at,
           e.started_at,
           e.completed_at,
           e.status
    FROM skill_flow_execution e
    WHERE e.trigger_type = 'AUTO_METRIC'
      AND e.created_at::date = CURRENT_DATE
)
SELECT
    t.id                                    AS "执行ID",
    t.flow_name                             AS "任务名称",
    t.status                                AS "任务状态",
    t.created_at                            AS "调起时间",
    t.started_at                            AS "开始执行时间",
    t.completed_at                          AS "完成时间",
    ROUND(EXTRACT(EPOCH FROM (t.completed_at - t.started_at)) / 60.0, 1)
                                            AS "执行耗时(分钟)",
    MIN(n.sent_at)                          AS "首封邮件发送时间",
    MAX(n.sent_at)                          AS "最后一封邮件发送时间",
    MAX(n.recipient)                        AS "邮件接收人"
FROM today_auto_exec t
LEFT JOIN skill_flow_notification n
       ON n.flow_execution_id = t.id
      AND n.status IN ('SENT', 'ACCEPTED', 'SIMULATED')
      AND n.sent_at IS NOT NULL
GROUP BY t.id, t.flow_name, t.status, t.created_at, t.started_at, t.completed_at
ORDER BY t.created_at;
```
