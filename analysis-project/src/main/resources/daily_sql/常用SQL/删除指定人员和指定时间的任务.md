# 任务执行记录清理 SQL（GaussDB）

> 用途：删除指定人员的长任务/独立任务，或按完成时间删除历史任务。
>
> 说明：
> - 只删除终态记录，保留 `WAITING_METRICS`、`QUEUED`、`RUNNING` 等未完成任务。
> - 执行前先修改“参数区”中的用户 ID 和时间；先执行预览 SQL，确认数量后再执行对应删除 SQL。
> - 所有删除均按外键依赖顺序执行：节点尝试 → 节点执行 → 通知 → 父执行。
> - 不删除 `skill_flow`、`skill_flow_node`、`skill_job` 等任务定义。

## 二、执行前预览（只读）

### 2.1 按人员预览长任务和独立任务

```sql
-- 替换：'用户ID'
SELECT '长任务' AS task_type, e.id, e.trigger_user_id AS user_id,
       e.status, e.created_at, e.completed_at
FROM skill_flow_execution e
WHERE e.trigger_user_id = '用户ID'
  AND e.status IN ('SUCCESS', 'PARTIAL_SUCCESS', 'FAILED', 'CANCELLED')
UNION ALL
SELECT '独立任务' AS task_type, e.id, j.created_by AS user_id,
       e.status, e.created_at, e.completed_at
FROM skill_job_execution e
JOIN skill_job j ON j.id = e.job_id
WHERE j.created_by = '用户ID'
  AND e.status IN ('SUCCESS', 'FAILED', 'SKIPPED')
ORDER BY created_at;
```

### 2.2 按时间预览长任务和独立任务

```sql
-- 替换：TIMESTAMP '2026-10-01 00:00:00'
SELECT '长任务' AS task_type, count(*) AS execution_count
FROM skill_flow_execution
WHERE status IN ('SUCCESS', 'PARTIAL_SUCCESS', 'FAILED', 'CANCELLED')
  AND completed_at < TIMESTAMP '2026-10-01 00:00:00'
UNION ALL
SELECT '独立任务' AS task_type, count(*) AS execution_count
FROM skill_job_execution
WHERE status IN ('SUCCESS', 'FAILED', 'SKIPPED')
  AND completed_at < TIMESTAMP '2026-10-01 00:00:00';
```

## 三、按人员删除长任务

```sql
-- 替换：'用户ID'
-- 1. 删除节点尝试
DO $$
DECLARE deleted_rows bigint;
BEGIN
  LOOP
    DELETE FROM skill_flow_node_attempt a
    WHERE a.id IN (
      SELECT a1.id
      FROM skill_flow_node_attempt a1
      JOIN skill_flow_node_execution n ON n.id = a1.node_execution_id
      JOIN skill_flow_execution e ON e.id = n.flow_execution_id
      WHERE e.trigger_user_id = '用户ID'
        AND e.status IN ('SUCCESS', 'PARTIAL_SUCCESS', 'FAILED', 'CANCELLED')
      LIMIT 5000
    );
    GET DIAGNOSTICS deleted_rows = ROW_COUNT;
    RAISE NOTICE '长任务节点尝试删除 % 行', deleted_rows;
    EXIT WHEN deleted_rows = 0;
  END LOOP;
END $$;

-- 2. 删除节点执行
DO $$
DECLARE deleted_rows bigint;
BEGIN
  LOOP
    DELETE FROM skill_flow_node_execution n
    WHERE n.id IN (
      SELECT n1.id
      FROM skill_flow_node_execution n1
      JOIN skill_flow_execution e ON e.id = n1.flow_execution_id
      WHERE e.trigger_user_id = '用户ID'
        AND e.status IN ('SUCCESS', 'PARTIAL_SUCCESS', 'FAILED', 'CANCELLED')
      LIMIT 5000
    );
    GET DIAGNOSTICS deleted_rows = ROW_COUNT;
    RAISE NOTICE '长任务节点执行删除 % 行', deleted_rows;
    EXIT WHEN deleted_rows = 0;
  END LOOP;
END $$;

-- 3. 删除流程通知
DELETE FROM skill_flow_notification n
WHERE n.flow_execution_id IN (
  SELECT e.id FROM skill_flow_execution e
  WHERE e.trigger_user_id = '用户ID'
    AND e.status IN ('SUCCESS', 'PARTIAL_SUCCESS', 'FAILED', 'CANCELLED')
);

-- 4. 删除长任务父执行
DELETE FROM skill_flow_execution e
WHERE e.trigger_user_id = '用户ID'
  AND e.status IN ('SUCCESS', 'PARTIAL_SUCCESS', 'FAILED', 'CANCELLED');
```

## 四、按人员删除独立任务

```sql
-- 替换：'用户ID'
-- 独立任务的执行记录没有 created_by，必须通过 skill_job.created_by 关联任务定义。
-- 1. 删除独立任务通知
DELETE FROM skill_job_notification n
WHERE n.execution_id IN (
  SELECT e.id
  FROM skill_job_execution e
  JOIN skill_job j ON j.id = e.job_id
  WHERE j.created_by = '用户ID'
    AND e.status IN ('SUCCESS', 'FAILED', 'SKIPPED')
);

-- 2. 分批删除独立任务执行记录
DO $$
DECLARE deleted_rows bigint;
BEGIN
  LOOP
    DELETE FROM skill_job_execution e
    WHERE e.id IN (
      SELECT e1.id
      FROM skill_job_execution e1
      JOIN skill_job j ON j.id = e1.job_id
      WHERE j.created_by = '用户ID'
        AND e1.status IN ('SUCCESS', 'FAILED', 'SKIPPED')
      LIMIT 5000
    );
    GET DIAGNOSTICS deleted_rows = ROW_COUNT;
    RAISE NOTICE '独立任务执行删除 % 行', deleted_rows;
    EXIT WHEN deleted_rows = 0;
  END LOOP;
END $$;
```
