# 10. `execute()`

```java
private void execute(
        String jobId,
        EvolutionTrigger trigger) {

    String lockName =
            "skill_evolution:" + trigger.skillName();

    boolean locked = false;

    try {

        // ① GET_LOCK
        locked = acquireLock(lockName);

        if (!locked) {
            jobRepo.fail(
                    jobId,
                    "EVOLUTION_LOCK_BUSY"
            );
            return;
        }

        jobRepo.running(jobId);

        // ② EXTRACT
        SkillEntry skill =
                indexRepo.findByName(trigger.skillName())
                        .orElseThrow(() ->
                                new IllegalStateException(
                                        "skill not found: "
                                        + trigger.skillName()
                                ));

        String oldBody =
                readSkillBody(trigger.skillName());

        int baseVersion = skill.version();

        jobRepo.extracted(
                jobId,
                baseVersion
        );

        // ③ MUTATE
        jobRepo.mutating(jobId);

        MutationResult mutation =
                mutate(
                        trigger,
                        oldBody,
                        baseVersion
                );

        // ④ VALIDATE
        jobRepo.validating(jobId);

        validator.validate(
                trigger.skillName(),
                oldBody,
                mutation.bodyPatch(),
                baseVersion
        );

        // ⑤ candidate
        String candidateId =
                candidateRepo.createEvolutionCandidate(
                        trigger.skillName(),
                        baseVersion,
                        mutation.bodyPatch(),
                        strategy
                );

        jobRepo.candidateCreated(
                jobId,
                candidateId
        );

        // ⑥ Golden
        jobRepo.goldenEvaluating(jobId);

        GoldenGateResult gate =
                runGolden(
                        trigger.skillName(),
                        baseVersion,
                        candidateId,
                        mutation
                );

        if (!gate.passed()) {

            candidateRepo.rejectEvolutionCandidate(
                    candidateId,
                    "GOLDEN_GATE_FAILED"
            );

            jobRepo.rejected(
                    jobId,
                    "GOLDEN_GATE_FAILED"
            );

            return;
        }

        // ⑦ 人工审批
        candidateRepo.markReviewRequired(
                candidateId
        );

        jobRepo.reviewRequired(jobId);

    } catch (Exception e) {

        jobRepo.fail(
                jobId,
                e.getMessage()
        );

    } finally {

        if (locked) {
            releaseLock(lockName);
        }
    }
}
```

# 11. 真实锁

不要继续使用：

```java
indexRepo.tryAcquireEvolveLock()
```

因为已经确认它是 NO-OP。

建议：

```java
private boolean acquireLock(String skillName) {

    String sql =
        "SELECT GET_LOCK(?, 5)";

    Integer result =
        jdbcTemplate.queryForObject(
            sql,
            Integer.class,
            "skill_evolution:" + skillName
        );

    return Integer.valueOf(1).equals(result);
}
```

释放：

```java
private void releaseLock(String skillName) {

    jdbcTemplate.queryForObject(
        "SELECT RELEASE_LOCK(?)",
        Integer.class,
        "skill_evolution:" + skillName
    );
}
```

### 注意

这里有一个实施层面的重要问题：

**GET_LOCK 是连接级锁。**

所以不能：

```text
拿连接 A GET_LOCK
↓
切换连接 B
↓
RELEASE_LOCK
```

必须保证 lock 生命周期绑定同一个 JDBC connection。

因此最终实现不要简单用普通：

```java
JdbcTemplate.queryForObject()
```

然后假设连接一直相同。

建议：

```java
dataSource.getConnection()
```

显式持有：

```java
Connection connection
```

直到整个 `execute()` 完成。

# 12. Mutation 两条 Arm

```java
private MutationResult mutate(
        EvolutionTrigger trigger,
        String oldBody,
        int baseVersion) {

    if ("llm".equalsIgnoreCase(strategy)) {

        DistilledSkill distilled =
                distiller.evolve(
                        trigger.skillName(),
                        oldBody,
                        trigger.exemplarQuestion(),
                        trigger.failedTrace()
                ).block();

        return convertDistilledToPatch(
                oldBody,
                distilled,
                baseVersion
        );
    }

    if ("gepa".equalsIgnoreCase(strategy)) {

        return gepaClient.evolve(
                new GePaRequest(
                        trigger.skillName(),
                        oldBody,
                        trigger.exemplarQuestion(),
                        trigger.failedTrace(),
                        baseVersion,
                        strategy
                )
        );
    }

    throw new IllegalArgumentException(
            "unsupported evolution strategy: " + strategy
    );
}
```

这里非常关键：

> **`SkillDistiller.evolve()` 的返回是完整 body，而 GEPA 返回 patch。**

因此 LLM arm 也需要：

```text
oldBody
+
newBody
↓
Diff
↓
body_patch
```

最终进入统一 Patch 管线。

# 22. `applyPatch()` 示例框架

```java
@Transactional
public PatchApplyResult applyPatch(
        String skillName,
        String description,
        int baseVersion,
        List<PatchOperation> operations) {

    SkillEntry current =
        indexRepository.findByName(skillName)
            .orElseThrow();

    if (current.version() != baseVersion) {
        throw new OptimisticLockException(
            "base_version=" + baseVersion +
            ", current_version=" + current.version()
        );
    }

    String currentBody =
        readSkillBody(skillName);

    String patchedBody =
        patchEngine.apply(
            currentBody,
            operations
        );

    validator.validatePatchedBody(
        skillName,
        currentBody,
        patchedBody,
        baseVersion
    );

    int newVersion =
        current.version() + 1;

    String content =
        renderFrontmatter(
            skillName,
            description,
            newVersion
        )
        + "\n"
        + patchedBody;

    int affected =
        indexRepository.updateVersionCas(
            skillName,
            baseVersion,
            newVersion
        );

    if (affected != 1) {
        throw new OptimisticLockException(
            "version changed concurrently"
        );
    }

    SkillFileSystemHelper.saveSkills(
        skillsDir,
        skillName,
        content
    );

    indexRepository.resetCounts(skillName);

    return new PatchApplyResult(
        skillName,
        baseVersion,
        newVersion
    );
}
```

# 30. Java `GePaClient`

```java
@Component
public class GePaClient {

    private final WebClient webClient;

    public MutationResult evolve(
            GePaRequest request) {

        GePaResponse response =
            webClient.post()
                .uri("/evolve")
                .bodyValue(request)
                .retrieve()
                .bodyToMono(GePaResponse.class)
                .block(Duration.ofMinutes(10));

        if (!response.success()) {
            throw new GePaException(
                response.errorCode(),
                response.message()
            );
        }

        return new MutationResult(
            response.baseVersion(),
            response.bodyPatch().operations(),
            "gepa",
            response.gepaTrace().model(),
            objectMapper.writeValueAsString(
                response.gepaTrace()
            )
        );
    }
}
```
